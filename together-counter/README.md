# Andries ♥ Crisstel widget

Standalone Android home-screen widget project in `together-counter/`.

Start: September 19, 2026 at 8:46 PM, interpreted in the phone's local timezone.
Transparent background; configurable heart selection (yellow, blue, green, or all three). The widget uses Android's native Chronometer for local elapsed-time ticking. Android may restrict widget redraws; the Chronometer itself is local and needs no network.

## Build
Open the repository's Actions tab and run **Build Andries Crisstel Widget**. Download the **Andries-Crisstel-Widget-APK** artifact from the completed run, extract it, and install app-debug.apk on the phone. Add the widget from the home-screen Widgets picker.

This is an early build. Typeface selector UI is included, but custom font rendering is not yet wired up in this version.
